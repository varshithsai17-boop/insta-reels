# insta reels

Before building or editing any reel in this folder, read `VIDEO-RULES.md` and apply it as recommended defaults. They are not hard constraints: use judgment, and note any deliberate deviation in that reel's `README.md`.

For how a reel is built step by step (scripting, scene, sound, the GPU renderer, checks, where files go), read `REEL-BUILD-PLAYBOOK.md`.
